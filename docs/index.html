Stateful Execution Engine

A "Relay Runner" pattern that mathematically guarantees background execution without hitting Google's 6-minute timeout wall.

(Clears Execution Tokens)
2. Run Loop Iterator
(Process Next URL)
Time < 4.5 Mins
3. Fetch PageSpeed Insight
Time ≥ 4.5 Mins Trigger Wall
4. Serialize VDB_STATE
5. Flush Memory Arrays to Sheet
6. Spawn continueRelayScan (60s)

Strict Abstraction

Decoupled Config
